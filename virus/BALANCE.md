# 健康小卫士 · 数值平衡表

所有数值均来自 `game.js`（`levelInfo` / `UPS` / `pcSpec` / `COLORS`），改数值请同步更新本表。

## 1. 关卡与病毒

- 每关基础血量 `H0 = 100 × 1.13^(L−1)`（取整到 10）；病毒分 4 个体型，血量 = H0 × [0.3, 0.5, 0.75, 1] × 随机 0.85–1.15。
- 病毒缓慢下落（drift），左右撞墙反弹（side），掉出底部即消失并记 1 次「漏网」（不扣血，只影响星级）。
- 体型 ≥1 的病毒被消灭后分裂成 2 个小一号病毒（血量 = H0×下一档×0.8），向两侧弹开。
- 碰到防护罩：扣 1 点护盾血（共 3 点，♥），1.6 秒无敌；伴随震动 `[70,40,90]` + 屏幕抖动 + 罩子变红/裂纹。
- 第 2 章起出现「铁甲」病毒（非蓝色药丸伤害 ×0.6），第 3 章起出现「快速」病毒（血量 ×0.7，速度更快）。
- 前两关特别温和：只出现小/中体型，生成间隔约 3.4 秒。
- 星级：0 伤 0 漏网 ★★★；伤 ≤1 且漏网 ≤2 ★★；其余 ★。
