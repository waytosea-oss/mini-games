## 镜头与装配约定（给哈利）

- 电台近景桌面加救援地图。不要水平翻转场景或地图：灯塔、旧码头等方位必须保持固定。返程队标可沿竖轴镜像以表示折返方向。
- 这是虚构海岸夜班。所有呼叫均为虚构剧情，不接入真实电话、位置或紧急救援服务。
- 每次回复与派遣推进明确的剧情时间，阅读日志不扣时间。
- 未经核实的坐标标为不确定，可先问关键问题；确认行动后写入可追溯事件树。
- 两支救援队有待命、出发、途中、返程状态。占用时不能瞬移接另一任务；改派有公开时间成本。
- 没有唯一完美结局。结束要能从已给线索解释信息、选择与资源如何导致结果，允许跳回关键节点。
- 首版：文字加音效、三呼叫、两队、一个完整可解释结章。不做真人求救接入、全分支配音或无限开放叙事。首版只做这一夜、这一张虚构海岸地图。
- 剧情时间可用无数字钟面加指针（指针绕轴心旋转），或一截琥珀弧：先铺 fill 再叠 frame。时间成本用一至三枚圆点分段，不要写分钟数字。
- 游戏里的字由代码叠上。本包画面不要写字、不要写阿拉伯数字、不要用表情符号。不要把概念稿里的「第一次夜班」「23:40」「救援队 1 空闲」「剧情时间 23:40」「甲？」「乙？」「二队待命」「频道 3 · 甲」「问地面和风向」「核实」等字样画进素材。
