# 野光图鉴

短名 `wildlight`。用浏览器打开本目录的 `index.html`，或从 `b3/index.html` 点进这张卡片。返回只链到 `../index.html`。进度存在这台设备的 `wildlight_save_v1`。

## 吉祥物

吉祥物名为「羽仔」。约两头身的原创林鸟活物：灰帽、奶油胸、苔绿翅、日光金尾扇。名字只写在文档里，没有画进画面。

封面动画用羽仔的精灵表。林中可拍的是另一只更写实的小型鸟：灰背、奶油胸、长条日光金尾。

精灵表用品红幕 `#FF00AA` 扣过，已经带透明通道，运行时直接使用。若以后重做去溢色，要保护绿大于红的苔藓、叶子和鸟羽，以及日光金尾与奶油胸，以免苔藓被抠穿。

## 封面动画

默认循环 `fan`：12fps，6×4 共 24 帧，单帧 480×404，锚点约 (219.5, 228.5)，取第零帧最大连通域质心，不用画布中心。悬停切 `look`（378×358，锚点约 (184.5, 181.5)），点击或进入林地时切 `hop`（396×458，锚点约 (196.5, 282.5)）。
