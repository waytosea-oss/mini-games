# 方寸生态

试玩短名 `feltisle`。存档键 `feltisle_save_v1`。返回只链到 `../index.html`。

## 屿仔

吉祥物的正式名是「屿仔」。这只名字只写在这份说明里，不写进画面，也不写成现生种学名。

形象是森林绿毛毡岛灵：肚上贴着湖蓝毛毡水洼，脚上是沙黄毛毡靴，头顶一束沙黄芦穗。动画用品红 `#FF00AA` 抠像，不用绿幕。去溢色时保住绿大于红的毛毡和苔面，也保住湖蓝水面和沙黄靴。

候选 B 的备选名是「泽仔」，湖蓝陶土小兽，更偏泽地。候选 C 是沙黄毛毡种籽身，没有另取正式名。这两个候选都不叫屿仔，也不进入可玩角色。

## 可玩物种

三种物种是单独的毛毡微缩，按公开栖地出现：

- 林栖种：枝角绿毡小兽。教学要两块相连的林地，正式岛要四块林地连成一片。
- 林缘种：叶帽沙黄圆兽。教学要草地贴住林地，正式岛要草地与林地至少共享三条边。
- 水岸种：芦冠湖蓝涉水鸟。连续水岸来自水系、湿地，以及带溪流的林地和草地。教学要两块相连，正式岛要四块相连。

出现时用带浅金圈的静帧，闲置没有金圈。

## 玩法

俯视平顶六角。`size = 236`，锚点在画布中心 `(256, 256)`。边从平顶边起顺时针编号 0 到 5。新地块必须贴住已有的岛。点选或拖到空位，旋转查看接口，确认前能看到两条弧线的变化。长按物种查看栖地。

河流接口对不上，就用红色六角标出。开口朝向岛外不算接错。受损沙黄起始底格只用于开局，不能从候选里拿到。

正式岛在十五片内同时满足连通和多样性。连通要河口对齐，并且三种栖地都成立。多样性要四种栖地都有，任何一种不超过五块。单一栖地铺得太多，会挤占最少的那种需求，对应的物种会离开。

三种栖地同时成立，并且林地连通块贴住水岸时，补两片。水岸延长到六块再补两片。补片一共两次。

没稳住可以复盘每一步的弧线变化，再试一次。教学关可以连续撤回。刷新后从本机存档继续。

音乐在第一次点按之后循环播放，可以开关。页面切到后台时会暂停。
