二、我们收集什么

游戏屋不需要注册，不收集姓名、手机号、邮箱、通讯录、精确定位等信息。为了解哪些游戏好玩、哪一关太难，网页中的统计脚本（track.js）会向我们的服务器（trigger-tech.fun/games/api/collect.php）发送以下匿名的玩法统计：

标识浏览器本地随机生成的访客 ID 与会话 ID（存放在本机 localStorage，可随时清除），用于区分新老访客、计算会话时长。
设备设备类型（手机/平板/电脑）、系统与浏览器大类及版本、手机品牌与型号（由浏览器提供的型号信息或屏幕尺寸推断）、屏幕尺寸与像素比、是否触屏、CPU 核数与内存档位（仅用于机型分组）、语言。浏览器不再上报完整 User-Agent 字符串；服务器只在内存中解析请求自带的 User-Agent 得到上述大类，原文不保存。
地区服务器根据请求的 IP 地址，在内存中通过离线库查出国家、省份、城市与运营商大类（电信/联通/移动等），只保存到城市级。IP 地址本身不写入数据库；仅以加盐哈希的形式在一分钟级的限流表中短暂使用以防刷量，随后清理。
来源来源网站域名、链接中的 utm/from 推广参数、从游戏屋的哪个位置进入游戏。
游戏事件打开页面、开始/通关/失败/退出某关、用时、得分与星级、暂停、复活、音效开关、返回游戏屋、页面停留与活跃时长。

我们不使用第三方统计、广告或社交 SDK，不做跨站跟踪，不做设备指纹识别，也不把数据出售或提供给第三方。

三、用途

上述数据仅用于统计游戏的访问量、各关卡难度与流失点、设备兼容情况和推广渠道效果，从而改进游戏。统计看板只供运营者内部查看。

四、本地存储

游戏会在你的浏览器 localStorage 中保存游戏进度、最高分、音效设置，以及上述随机 ID 和「是否已看过统计提示 / 是否关闭统计」的选择。这些数据留在你的设备上，清除浏览器网站数据即可删除。

五、保存与安全

统计数据保存在运营者自有服务器的数据库中，看板需密码登录。保存期限：待补充。

六、关闭统计

本浏览器的统计状态：…

关闭后，track.js 在本浏览器中不再发送任何统计，并删除本机保存的随机 ID；游戏照常可玩。开启浏览器的“请勿跟踪”（Do Not Track）或 GPC 设置也会停止统计。关闭对 trigger-tech.fun 与 github.io 两个站点分别生效。

七、未成年人

游戏屋面向所有年龄段，不要求提供任何身份信息。未成年人请在监护人指导下游玩，并注意游戏时长。

八、你的权利与联系我们

由于我们不收集可识别你身份的信息，通常无法把统计记录与具体个人对应。如需查询、删除与某个访客 ID 相关的数据，或对本政策有疑问，请通过第一节的联系方式联系我们（联系方式待补充）。本政策如有更新，将在本页面公布。
